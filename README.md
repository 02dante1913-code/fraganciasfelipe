# Fragancias Felipe

Landing page de Fragancias Felipe, perfumería árabe premium en Córdoba, Argentina.

Sitio estático de una sola página (HTML + Tailwind CSS vía CDN), con un asesor interactivo que arma una consulta lista para enviar por WhatsApp.

## Desarrollo local

Abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor estático.

## Despliegue

Desplegado en [Vercel](https://vercel.com) como sitio estático.
